# Nature Communications Fig. 5a — spatial point map

This gallery case is a candidate, case-specific recovery of visible PDF-vector point marks. `data.csv` contains the 426 categorical-region spots and 3,424 colour-mapped spots that are directly visible in the figure. The right-map `value` field is an approximation from the printed colourbar and is never author raw data. No physical spatial coordinates, cell IDs, or unrendered probabilistic values are claimed.
